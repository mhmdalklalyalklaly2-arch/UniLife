# UniLife — حياة الطالب الجامعي

تطبيق Flutter عربي (RTL) لإدارة الحياة الجامعية محليًا دون الحاجة إلى حساب أو اتصال بالإنترنت. يحتوي المشروع على صورة مبنى الجامعة المرفقة، وهوية بصرية موحّدة، وقاعدة SQLite محلية.

## الوحدات الموجودة
- ملف الطالب الأكاديمي قابل للتعديل.
- لوحة رئيسية بإحصائيات وروابط إلى الوحدات.
- المواد الدراسية.
- الجدول الأسبوعي مع إضافة/تعديل/حذف المحاضرات.
- الواجبات والمشاريع مع حالات قابلة للاختيار.
- سجلات الحضور والغياب والتأخر والعذر.
- تسجيل الدرجات مع تحقق رقمي وعرض نسبة الدرجة عند توفر الدرجة الكلية.
- إعدادات الوضع الليلي ومعلومات التطبيق.

## البناء
1. افتح مجلد `UniLife` في بيئة Flutter.
2. نفّذ `flutter pub get`.
3. نفّذ `flutter analyze` ثم `flutter test` إن توفرت الاختبارات.
4. نفّذ `flutter build apk --release`.
5. ملف APK المتوقع: `build/app/outputs/flutter-apk/app-release.apk`.

## تنبيه مهم
هذا أرشيف مصدر Flutter وليس APK جاهزًا. لم يُنفّذ بناء Android أو اختبار على جهاز حقيقي في هذه البيئة؛ يجب تشغيل أوامر الفحص والبناء أعلاه ومعالجة أي ملاحظات تظهر. تُحفظ البيانات محليًا، وقد تفقد عند حذف بيانات التطبيق أو إلغاء تثبيته ما لم تُصدّر نسخة احتياطية.
